Integrasi Google Sheets

Aplikasi **Nusantara Wifi** dapat mengirimkan setiap data penarikan secara otomatis ke Google Sheets Anda menggunakan Webhook Google Apps Script (GAS).

Cara Membuat Kode Google Apps Script:

  1. Buka Google Sheets Anda di Laptop/HP.
  2. Klik menu **Extensions (Ekstensi)** > **Apps Script**.
  3. Hapus semua kode lama, lalu **Copy-Paste** kode di bawah ini:

4. Klik **Deploy** > **New deployment** > Pilih **Web app** > Set access to **"Anyone" (Siapa Saja)** > Lalu salin Web App URL-nya ke kotak di atas.
